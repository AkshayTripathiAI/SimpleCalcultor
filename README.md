# SimpleCalculator

A minimal two-number calculator web page built with HTML, CSS and vanilla JavaScript.

Built as an early practice project while learning JavaScript.

## Features

- Enter two numbers and choose an operator: add, subtract, multiply or divide.
- Click "Calculate" to show the full equation and result, e.g. `6 * 7 = 42`.
- Invalid (non-numeric) input clears the result instead of showing an error.

## Tech stack

- HTML, CSS, vanilla JavaScript
- Bootstrap 4 (button styling, loaded from CDN)

## Getting started

No build step or dependencies.

```bash
git clone https://github.com/AkshayTripathiAI/SimpleCalcultor.git
cd SimpleCalcultor
```

Open `index.html` in a browser.

## Project structure

```
index.html   # Markup: two inputs, operator select, Calculate button
script.js    # calculate() logic
style.css    # Styles
```
